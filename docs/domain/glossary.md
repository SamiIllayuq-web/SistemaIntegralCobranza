
# Glosario del dominio


## Cliente moroso

Persona natural con una deuda en estado de mora. Se identifica por RUT/DNI.


## Cartera de cobranza

Conjunto de deudas que una entidad financiera le encarga al estudio jurídico para gestionar.


## Entidad financiera

Banco, financiera o retail que origina la deuda y encarga la cobranza.


## Importación

Proceso de subir un Excel de cartera y poblar/actualizar la base de datos.


## Exportación

Proceso de generar el Excel que la entidad financiera espera recibir para reportar la gestión.


## Reporte de gestión

Archivo Excel (o equivalente) que el estudio le entrega a la entidad

periódicamente con el estado de las deudas gestionadas.
